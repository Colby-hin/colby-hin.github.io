# colby-hin.github.io

Personal site for Colby Hinchy — cybersecurity professional (Governance, Risk, and Compliance).

## Structure

```
index.html                        single self-contained page (HTML + CSS + JS)
assets/colby-hinchy-resume.pdf    resume, linked from the nav, hero, and contact section
sitemap.xml                       search engine sitemap
robots.txt                        crawler directives
```

There is no build step and there are no dependencies. Edit `index.html` directly and push.

## Deploying

Served by GitHub Pages from the `main` branch, root folder.
Settings -> Pages -> Deploy from a branch -> main -> / (root)
